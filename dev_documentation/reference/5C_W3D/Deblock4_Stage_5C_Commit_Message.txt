Stage 5C: Classic v3 (AVX2-class) 256-bit backend, byte-identical to the scalar oracle

Instantiates the SAME frozen width-generic vector body at 256-bit - u8 N=32,
u16 N=16 - in a new thin object compiled at the exact named x86-64-v3 level.
No new mathematics: the scalar oracle, edge schedule, thresholds, the
width-generic vector body and the accepted v2 SSE4.1 object are all untouched.

Identity advances to 0.1.0-dev+5C.

Proof (build_5C_v1.bat, OUTER_BATCH_EXIT_CODE=0; evidence retained under
zig-out/inspection_5C):
- 5C-T1  35/35 vector tests in Debug/ReleaseSafe/ReleaseFast across two
         v3-target legs: the frozen body's 28 plus 7 new 5C tests covering
         every u8 remainder 1..31 and u16 1..15 (8 seeded trials each), D3
         fixtures at the new widths, the exhaustive 8-bit lane sweep,
         deliberately non-16/32-byte-aligned bases, non-vector strides,
         prefix/row-slack/suffix canaries, and vertical bottom underfill
         at 1, 2 and 3 rows.
- 5C-T2  Scalar-vs-v2-vs-v3 differential ALL_PASS over 17 cases, 0 differing
         bytes, region-targeted non-vacuity satisfied on every case;
         remainder classes 1/15/16/17/31 forced on luma and on the chroma
         planes of legal even-width 4:2:0/4:2:2 frames.
- 4C     Retained 18-case scalar-vs-v2 regression ALL_PASS on the same DLL.
- 5C-T3  Containment: the v3 object carries YMM work and vzeroupper; the v2
         object carries no YMM; narrower operations inside the v3 object are
         the legitimate descending-tail sub-instantiations. No backend C
         root appears in the DLL export table.
- 5C-T4  Selection: auto resolves to v3 capability-derived; explicit v1, v2
         and v3 are all accepted; the retired intentionally-capped(v2)
         expectation is asserted absent.
- 5C-T5  Negative controls fired correctly: named-model perturbation rejected
         for both the v2 and v3 guards; a one-lane V1 tail mutation applied
         to an out-of-repo copy was caught by the frozen-body tests, by the
         new 5C tests and by the differential.
- 2C/1C  Full retained surface re-executed green, including 85/85 unit tests
         in three modes and ReleaseSafe==ReleaseFast production byte
         identity.

Benchmark (recorded, never gated - S5C-3): 720x576 YUV420P8, strength 25,
240 frames, one discarded warm-up plus three recorded runs per backend:
v1 0.3182 s, v2 0.2853 s, v3 0.2770 s. AVX2 is about 1.15x scalar and only
about 3 percent faster than SSE4.1, as the ratified design predicts: the
vertical path is width-invariant by algorithm and the filter is
substantially memory-bound. Recorded as knowledge K34; no number is
normative.
