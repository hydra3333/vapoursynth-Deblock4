# Scope-header reminder block: C-DELIV-09 (copy verbatim into every scope header)

The following block is copied VERBATIM into the header of every scope and every
delivery-plan addendum, immediately after the encoding/EOL line, as a standing
reminder of charter C-DELIV-09.

---8<--- BEGIN C-DELIV-09 SCOPE-HEADER BLOCK (copy verbatim) ---8<---

**Incremental emission (charter C-DELIV-09) - standing reminder:** For this
scope/phase, W3C emits completed work to W3X INCREMENTALLY as each module (or
small coherent group) is finished, each marked "increment N of ~M: <what>".
The increments are for interrupt-safety and review continuity: if the session
is interrupted, the recoverable baseline is the last COMPLETE emitted
increment, and at most the module in flight is lost. ONLY DELIVERED ARTIFACTS
SURVIVE - W3C does not claim to preserve or resume un-emitted internal work.
The increments do NOT replace the final deliverable: at scope/phase end, W3C
RE-PACKAGES the whole as one properly-formed deliverable of record meeting
C-DELIV-01..08 (exact base, per-file form, manifest, apply/validate discipline,
patch and/or whole-file plus the validation batch). The increments are a
running preview; the package is what W3X applies.

---8<--- END C-DELIV-09 SCOPE-HEADER BLOCK ---8<---

Note: the block is intentionally self-contained so it needs no cross-reference
to be understood by a memoryless W3C reading only the scope. It restates, does
not modify, charter C-DELIV-09; on any apparent conflict the charter governs.
